# How this compendium was built, and its limits

- **Catalog**: 790 entries = 304 from GameDecompLibrary (site `catalog.json`, snapshot 2026-10-04) + 482 from the Game-Decompilations list (2026-09-29) + 4 user-added sources (universal-modder, the two lists' repositories, decompedia). For every GitHub repo: public metadata (licence, stars, push date, archived, topics, default branch), root file listing and README were harvested with `gh api`; 23 repositories returned 404 (renamed/removed) and keep only list data.
- **Derived fields**: `summary` = first meaningful README sentence (or name/type/platform fallback); `compilers`/`tools`/`build` = keyword detection over the README and root listing; `platform`/`type` for list-sourced entries are *derived* from README keywords and marked "(derived)"; `ai` = hand classification for the clear cases, otherwise `mentions`/`unspecified` from a keyword heuristic with the evidence snippet (verify before relying on it); `depth` = how deeply the entry was read (`deep`: cloned and source/docs read; `readme`; `meta`).
- **Notes** (`note`, `use`) are hand-written for ~140 entries and limited to what was read; entries not read in depth say so.
- **Clones**: ~50 repos were cloned shallowly for reading (700 MB) and are not part of this repository. Use `scripts/clone.sh <id>` to fetch what you need.
- **Licences**: the catalog stores facts and short paraphrases. GameDecompLibrary, Game-Decompilations and decompedia state no licence: their text is not copied. universal-modder is MIT: its index metadata and short excerpts are included with attribution; full notes stay upstream. Code snippets from other projects are not copied; where a short idiom is described it is paraphrased with the source named. See THIRD_PARTY_NOTICES.md in the repository root.
- **Verification performed**: scripts in `re-binary-recon`, `game-asset-formats`, `decomp-matching-workflow` and `gamedecomp-library` were run on real binaries/files (x86 and x64 PEs, Steam game folders) and a throwaway claim queue; Oblivion facts were measured on a retail Steam install.
- **Known gaps**: ~90 entries are metadata-only; list-sourced platform/type may be wrong; AI-policy flags are incomplete; progress numbers come from the catalog snapshot and age quickly; nothing here has been tested on Windows paths.
- **Research graph, findings, experiments** (added 2026-10-06): hand-written from the project docs and the owner's measurements, validated by `refresh/build_knowledge.py`. The graph is deliberately small (about 90 nodes, 125 hand-written edges, 23 findings, 15 experiments): it records what a query needed, not everything known, and a missing edge means unknown. Most edges are `documented` (project docs, catalog entries, upstream READMEs); only edges with a measurement or a read of the binary carry `verified` or `static`. Almost all movement and collision evidence comes from one project (OpenOblivion), one game (Oblivion) and one data slice (Vilverin); treat family-level claims accordingly.
- **Gotcha extracts**: `data/modder-gotchas.json` holds short extracts (684 gotchas from 59 upstream notes at the revision in its meta); symptom headlines are verbatim, causes are clipped, some upstream gotchas have no explicit cause and show a detail excerpt instead.
- **Relevance tests**: `tests/golden_queries.json` (43 tests) pins where known-good answers appear; windows are deliberately wide. Ranking is a small BM25 with graph-alias expansion, per-kind diversification and a graph boost for projects linked to the query's named approach or platform; it is not semantic search, so synonyms need aliases or cues in `knowledge/graph/nodes.jsonl`.
